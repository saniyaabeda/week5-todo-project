# Smart To-Do List Application

## 1. Project Overview

The Smart To-Do List is a simple and interactive web application developed using HTML, CSS, and JavaScript. The purpose of this project is to help users organize and manage their daily tasks. Users can add tasks, select categories, search for tasks, mark tasks as completed, edit tasks, and delete tasks.

## 2. Features Implemented

The project includes several useful features:

- Add new tasks
- Select task categories
- Mark tasks as completed
- Undo completed tasks
- Edit existing tasks
- Delete tasks
- Search tasks
- Filter completed and pending tasks
- Dynamic task counter
- Empty task validation
- Interactive buttons

## 3. Technologies Used

The following technologies were used:

- HTML5 – Used to create the structure of the webpage.
- CSS3 – Used for styling, layout, buttons, cards, and responsive design.
- JavaScript – Used to implement application functionality and user interaction.

## 4. JavaScript Concepts Used

Several JavaScript concepts learned during the previous weeks were applied in this project.

Variables are used to store task data and HTML elements. Functions are used for adding, displaying, editing, deleting, and completing tasks. Arrays and objects are used to store task information. Conditional statements are used for validation and filtering. Loops and array methods such as filter(), find(), and forEach() are used to process tasks.

DOM manipulation is used to create and update task cards dynamically. Event listeners are used for button clicks, searching, filtering, and keyboard input.

## 6. Challenges Faced

One challenge was connecting JavaScript correctly with the HTML elements. Another challenge was dynamically displaying and updating tasks without refreshing the webpage. Handling search and filtering while maintaining the task data was also a challenge.

## 7. Solutions Implemented

The problems were solved by using DOM selection methods, event listeners, arrays, objects, and JavaScript functions. The displayTasks() function was created to update the task list whenever the task data changes.

Through this project, I learned how to combine HTML, CSS, and JavaScript to create a functional web application. I improved my understanding of arrays, objects, functions, DOM manipulation, events, and array methods. I also learned how to test and debug JavaScript code.

## 9. Future Improvements

In the future, the application can be improved by adding local storage so that tasks remain available after closing the browser. Login functionality, due dates, reminders, dark mode, and task priority can also be added.
